## Dashboard 1 — Sales Executive Analysis

An interactive Sales Performance Dashboard developed in Microsoft Excel to analyze sales performance, profitability, products, categories, and other key business metrics.

### Quick Access

- [Watch Demo](#dashboard-1-demo)
- [View Excel File](./Dashboard%201.xlsm)

### Key Features

- Interactive sales and profit analysis
- Monthly and daily performance tracking
- Top product and category identification
- Payment mode and sales type analysis
- Dynamic filtering using slicers
- Data cleaning and transformation with Power Query

### Tools Used

`Microsoft Excel` • `Power Query` • `Pivot Tables` • `Pivot Charts` • `Slicers`
